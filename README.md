# Onboarding Soft

## Getting Started

### Prerequisites

- WSL (Windows Subsystem for Linux)
- Node.js
- Make (optional)

### Installation & Setup

1. **Clone or download the repository**

```bash
git clone https://github.com/jeperico/onboarding-soft
```

or download as [ZIP](https://github.com/jeperico/onboarding-soft/archive/refs/heads/prod.zip)

2. **Extract to Downloads folder**

3. **Open WSL and navigate to the project**

```bash
cd /
cd /mnt/c/Users/[YOUR_USER]/Downloads/[PROJECT_FOLDER]/[PROJECT_FOLDER_IF_EXIST]
```

4. **Run the project**

```bash
make start
```

or

```bash
npm i
npm run dev
```

5. **Open in browser**
   Navigate to `http://localhost:3000` (or the port displayed in your terminal if 3000 is in use)
