# Onboarding Soft

## Getting Started

### Prerequisites

- WSL (Windows Subsystem for Linux)
- Make
- Node.js (or required runtime)

### Installation & Setup

1. **Clone or download the repository**

```bash
git clone https://github.com/jeperico/onboarding-soft
```

or download as [ZIP](https://github.com/jeperico/onboarding-soft/archive/refs/heads/prod.zip)

2. **Extract to Downloads folder**

```bash
unzip onboarding-soft.zip -d ~/Downloads/
```

3. **Open WSL and navigate to the project**

```bash
cd /mnt/c/Users/[YOUR_USER]/Downloads/onboarding-soft
```

4. **Run the project**

```bash
make run
```

5. **Open in browser**
   Navigate to `http://localhost:3000` (or the port displayed in your terminal if 3000 is in use)

---

**Note:** Ensure all dependencies are installed before running `make run`.
